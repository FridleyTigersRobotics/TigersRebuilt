XboxController:
Left Stick = Drive Field Oriented
Right Stick = Rotate
Press Right Stick = Aim at Alliance Hub
X = Stow Intake
A = Intake out
Right Trigger = Intake Flipper
Right Bumper = Intake Wheels
Left Bumper = Outtake Wheels
B = Defensive X Stance
Start = rehome intake angle

Buttons:
10 = Elevator Home
1 = Elevator Low
2 = Elevator Climb
3 = Elevator High
4 = Pass Short
5 = Pass Mid
6 = Pass Far
7 = Hub Shoot
8 = Index Shoot
9 = Index Reverse

PathPlanner Autonomous Commands:
Xstance            — Lock swerve in an 'X' stance for ~1.5 s or until autonomous ends (whichever comes first).
IntakeReverseTimed — Run intake wheels in reverse (open-loop outtake) for 1.0 s, then stop.
PrepBot            — Reverse intake briefly, lower intake to kIntakeDeg (wait w/ timeout), then raise elevator to kMaxHeight with intake interlock.
ElevatorLower      — Safely lower elevator to kMinHeight; homes first if needed and waits until at setpoint.
ElevatorRaise      — Safely raise elevator to kMaxHeight; homes first if needed, blocks if intake is stowed, and waits until at setpoint.
AutoShoot          — Aim at alliance hub (time-capped), spin up shooter using CalcAndSetShotCmd and wait for AtSpeed or timeout, feed indexer for a set time, then stop indexer & shooter and park hood at 0°. Aborts immediately when autonomous ends.
IntakeWheelsStart  — Start intake wheels (percent open-loop) and leave them running via SetWheelsPercent.
IntakeWheelsStop   — Stop intake wheels by setting duty to 0 via SetWheelsPercent(0.0).
intakeflip         — Move intake to target angle, pause, then return to kIntakeDeg; waits near tolerance with move timeouts.
